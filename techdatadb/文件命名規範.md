# 技術資料庫文件與目錄命名規範

本規範依據**產品技術資料五大架構**，並整合專案現有命名邏輯制定，旨在統一目錄層級、檔案命名規則，提升檢索效率、跨系統相容性與版控維護便利性。

---

## 一、 目錄結構規範（二層/三層架構）

根據架構圖，以「產品（品牌/產品線）」為根節點，下設 **五大核心文件類別**：

```
技術資料庫/
├── [產品編號].[品牌名稱]/
│   ├── 1.原理/
│   ├── 2.Brochure 目錄/
│   ├── 3.Application Note/
│   ├── 4.單一產品/
│   │   ├── TI_[品牌]_[型號]/              # 單一產品專屬資料夾（選填，多份文件時使用）
│   │   └── ...
│   └── 5.配方/
```

### 1.1 一級目錄（品牌 / 產品線）
* **命名規則**：`[序號].[品牌名稱]`
* **範例**：
  * `2.Tyzor`
  * `3.unilink`
  * `4.Orion`
  * `5. MPI`

### 1.2 二級目錄（五大類別）
嚴格對應架構圖五大分支，並維持數字編號以確保資料夾排序一致：

| 編號 | 目錄名稱範例 | 內容說明 |
| :--- | :--- | :--- |
| **1.** | `1.原理` 或 `1.Principle 原理` | 產品基礎科學原理、化學反應機制、技術背景介紹 |
| **2.** | `2.Brochure 目錄` | 總覽型錄、產品線手冊、選用指南總覽（15~16冊等） |
| **3.** | `3.Application Note` | 特定產業/加工應用的技術指南、選型手冊、操作指引 |
| **4.** | `4.單一產品` 或 `4.單一產品應用技術資料` | 單一型號之技術資料表（TDS/TI）、性能研究（Performance Study） |
| **5.** | `5.配方` 或 `5.Formulation 配方指南` | 配方指南（Formulation Guide）、起始配方建議、添加比例指引 |

### 1.3 三級目錄（單一產品子資料夾）
僅適用於 `4.單一產品` 目錄下，若該型號有多份相關報告時建立：
* **命名規則**：`TI [品牌] [型號]` 或 `TI_[品牌]_[型號]`
* **範例**：
  * `TI MPI Polyglide 1226 XF`
  * `TI_Tyzor Activate 422`
  * `TI Unilink 4200`

## 二、 檔案命名規範

### 2.1 命名通用公式

檔案名稱由 **6 個核心元素** 組成，建議採用標準底線 `_` 或單一空格區隔，語法如下：

```
【文件類型】_【公司/品牌】_【產品型號】_【主題/應用領域/研究名稱】_【語系】_【版本或日期】.pdf
```

> **注意**：若該文件無特定型號（如總覽 Brochure 或通則原理），則省略【產品型號】段落。

---

### 2.2 命名欄位定義與代碼清單

| 欄位 | 必填/選填 | 規範與常用代碼 | 說明與範例 |
| :--- | :---: | :--- | :--- |
| **① 文件類型** | **必填** | `Principle`<br>`Brochure`<br>`Application Note`<br>`TI` 或 `TDS`<br>`Formulation` | 嚴格對照五大架構：<br>• 原理：`Principle`<br>• 型錄：`Brochure`<br>• 應用手冊：`Application Note`<br>• 單一產品技術資料：`TI`（Technical Information）或 `TDS`<br>• 配方：`Formulation` 或 `Formulation Guide` |
| **② 公司/品牌** | **必填** | `DK Tyzor`<br>`DK Unilink`<br>`Orion`<br>`MPI` | 代理識別（如 `DK`）+ 原廠品牌名稱 |
| **③ 產品型號** | 選填 | `FW 310`<br>`PolyGlide 1226XF`<br>`Clearlink 1000`<br>`Activate 422` | 單一產品資料必填；總覽型錄或跨品項指南則省略 |
| **④ 主題/應用說明** | **必填** | 英文首字母大寫或慣用名詞片語 | 說明應用領域、指南類型或測試項目，例如：<br>• `WoodCoatings Selector Guide`<br>• `Food Packaging`<br>• `Printing Ink Rub Resistance Study`<br>• `Performance Study` |
| **⑤ 語系代碼** | **必填** | `EN`（英文）<br>`CN`（簡體中文）<br>`TW` / `ZH`（繁體中文） | 標註於檔名末段，大寫 2 碼 |
| **⑥ 版本或日期** | 選填/建議 | `YYYY`（如 `2026`）<br>`YYYYMM`（如 `202512`） | 統一採用 ISO 年月格式，避免中英月份混用 |

## 四、 命名品質規範與排錯清單（防呆原則）

為維護專案命名的一致性與系統相容性，必須遵守以下限制：

### ❌ 嚴格禁止的錯誤樣式
1. **拼字錯誤**：
   * ❌ `Borchure` ➔  **`Brochure`**
   * ❌ `Appilcation Note` / `Appication Note` ➔  **`Application Note`**
   * ❌ `Perfomance` ➔  **`Performance`**
2. **多餘空格與尾端孤立空格**：
   * ❌ `EN .pdf` ➔  **`EN.pdf`**
   * ❌ `TI  Dk Tyzor_IAM for  ink EN .pdf` ➔  **`TI DK Tyzor IAM for Ink EN.pdf`**
3. **大小寫混亂**：
   * ❌ `Dk` ➔  **`DK`**
   * ❌ `colour_black` ➔  **`Colour Black`**
4. **日期格式雜亂**：
   * ❌ 混用 `2022_Aug_25`、`2024_Jul`、`202512`
   *  統一使用 **`YYYY`**（如 `2026`）或 **`YYYYMM`**（如 `202407`）
5. **特殊符號**：
   * 檔名中請勿包含特殊符號（例如 `®`, `™`, `&`, `(`, `)`, `（`, `）`），避免跨系統或指令碼處理錯誤。
